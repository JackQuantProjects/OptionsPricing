# Options Pricing

This repository contains my notes, implementations, and projects while working through [Options Volatility & Pricing](https://www.amazon.co.uk/Option-Volatility-Pricing-Advanced-Strategies/dp/0071818774) by Sheldon Natenberg.

The goal is to take the concepts from the book and implement them in Python to build a stronger understanding of options pricing, volatility, and the mathematics behind options trading.

## Projects

### Volatility Surface

A Python implementation of an implied volatility surface using:

* Black-Scholes option pricing
* Newton-Raphson implied volatility calculation
* Real options data from yfinance
* Filtering of option contracts
* Matplotlib 3D volatility surface visualisation
* Unit testing for the pricing and numerical methods

The project explores how implied volatility varies with strike price and time to expiration.

## Learning

Alongside the projects, this repository will contain notes and implementations of concepts covered throughout the book, including:

* Options pricing
* The Greeks
* Implied volatility
* Volatility smiles and skews
* Volatility surfaces
* Hedging
* Numerical methods
* Options strategies

The focus is on learning by implementing the concepts rather than simply documenting the theory.
